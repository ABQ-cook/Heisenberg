# 函数常见内置属性

Python 函数对象的常见内置属性如下：

## **身份与文档类**

| 属性 | 说明 | 示例 |
| --- | --- | --- |
| `__name__` | 函数名（字符串） | `"get_weather"` |
| `__qualname__` | 完整限定名（含类名） | `"MyClass.method"` |
| `__doc__` | 文档字符串（docstring） | `"查询指定城市的天气"` |
| `__module__` | 函数定义所在的模块名 | `"__main__"` |

`__doc__`是写在函数定义里第一行的字符串内容

## **参数与签名类**

| 属性 | 说明 |
| --- | --- |
| `__defaults__` | 位置参数的默认值元组 |
| `__kwdefaults__` | 仅关键字参数的默认值字典 |
| `__code__` | 函数的字节码对象（含参数数量、变量名等） |
| `__annotations__` | 参数和返回值的类型注解字典 |

## **闭包与上下文类**

| 属性 | 说明 |
| --- | --- |
| `__closure__` | 闭包捕获的自由变量元组（无闭包则为 `None`） |
| `__globals__` | 函数所在模块的全局命名空间字典 |
| `__dict__` | 存放任意自定义属性的字典 |

## 实例演示：

```python
def greet(name: str, greeting: str = "Hello") -> str:
"""向某人打招呼"""
return f"{greeting}, {name}!"
```

```python
print(greet.**name**)        # greet
print(greet.**doc**)         # 向某人打招呼
print(greet.**module**)      # **main**
print(greet.**defaults**)    # ('Hello',)
print(greet.**annotations**) # {'name': <class 'str'>, 'return': <class 'str'>}
print(greet.**code**.co_varnames)  # ('name', 'greeting')
print(greet.**code**.co_argcount)  # 2
```
