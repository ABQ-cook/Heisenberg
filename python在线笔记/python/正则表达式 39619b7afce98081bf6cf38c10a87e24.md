# 正则表达式

## `group()`分组：

正则表达式用括号来进行所索取内容的分组，可以对所得的正则匹配内容使用group()方法取出对应的某一组，其中group的使用方法有：

group(0)代表不取某一组，进行完整匹配

group(1)代表取第一个括号内容，即第一组，剩下的以此类推

## 正则表达式常用符号速查表

### 一、字符匹配

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `.` | 匹配任意单个字符（除换行符） | `a.b` 匹配 `aab`、`acb` |
| `\d` | 数字 `[0-9]` | `\d{3}` 匹配 `123` |
| `\D` | 非数字 | `\D` 匹配 `a`、`#` |
| `\w` | 单词字符 `[a-zA-Z0-9_]` | `\w+` 匹配 `hello_123` |
| `\W` | 非单词字符 | `\W` 匹配 `@`、空格 |
| `\s` | 空白字符（空格、tab、换行） | `a\s+b` 匹配 `a b` |
| `\S` | 非空白字符 | `\S+` 匹配 `hello` |
| `\n` | 换行符 |  |
| `\t` | 制表符 |  |
| `[abc]` | 字符类：a 或 b 或 c | `[aeiou]` 匹配任一元音 |
| `[^abc]` | 否定字符类：非 a、b、c | `[^0-9]` 匹配非数字 |
| `[a-z]` | 字符范围 | `[A-Za-z]` 匹配任意字母 |
| `a|b` | 或：匹配 a 或 b | `cat|dog` |

### 二、锚点（位置匹配）

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| `^` | 行首 | `^Hello` 匹配行首的 Hello |
| `$` | 行尾（或换行前） | `end$` |
| `\A` | 字符串绝对开头 | 不受多行模式影响 |
| `\Z` | 字符串绝对结尾 | 不受换行影响 |
| `\b` | 单词边界 | `\bcat\b` 匹配独立的 "cat" |
| `\B` | 非单词边界 |  |

### 三、量词（重复次数）

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `*` | 0 次或多次 | `a*` 匹配 `""`、`a`、`aaa` |
| `+` | 1 次或多次 | `a+` 匹配 `a`、`aaa` |
| `?` | 0 次或 1 次 | `colou?r` 匹配 `color`、`colour` |
| `{n}` | 恰好 n 次 | `\d{3}` 匹配 3 位数字 |
| `{n,}` | 至少 n 次 | `\d{2,}` 匹配 2 位以上数字 |
| `{n,m}` | n 到 m 次 | `\d{2,4}` 匹配 2~4 位数字 |

### 四、贪婪 vs 非贪婪

| 符号 | 含义 |
| --- | --- |
| `.*` | **贪婪**：尽可能多匹配 |
| `.*?` | **非贪婪**：尽可能少匹配 |
| `.+?` | 非贪婪的 `+` |
| `??` | 非贪婪的 `?` |

```
文本: "<div>hello</div>"
<.*>    → 匹配整个 "<div>hello</div>"  (贪婪，一口吃到底)
<.*?>   → 匹配 "<div>"               (非贪婪，遇到第一个 > 就停)
```

### 五、分组与捕获

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `(...)` | **捕获组**：分组并捕获 | `(hello) (world)` → group(1)=hello, group(2)=world |
| `(?:...)` | **非捕获组**：仅分组，不捕获 | `(?:abc)+` 不占用 group 编号 |
| `(?P<name>...)` | **命名捕获组** | `(?P<year>\d{4})` → group("year") |
| `\1`, `\2` | 反向引用捕获组 | `(\w+)\s+\1` 匹配重复词如 "hello hello" |

### 六、零宽断言（Lookaround）

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `(?=...)` | **正向预查**：后面是... | `foo(?=bar)` 只匹配后面有 bar 的 foo |
| `(?!...)` | **负向预查**：后面不是... | `foo(?!bar)` 只匹配后面没有 bar 的 foo |
| `(?<=...)` | **正向回顾**：前面是... | `(?<=\$)123` 只匹配前面有 $ 的 123 |
| `(?<!...)` | **负向回顾**：前面不是... | `(?<!\$)123` 只匹配前面没有 $ 的 123 |

> **记忆技巧**：`=` 是"是"，`!` 是"不是"；不带 `<` 看右边，带 `<` 看左边。
> 

### 七、常用 `Flags` （ `re` 模块）

| Flag | 简写 | 含义 |
| --- | --- | --- |
| `re.IGNORECASE` | `re.I` | 忽略大小写 |
| `re.MULTILINE` | `re.M` | `^` `$` 匹配每行首尾 |
| `re.DOTALL` | `re.S` | `.` 匹配包括换行符 |
| `re.VERBOSE` | `re.X` | 允许写注释和空白，提高可读性 |
