# 形参中的解包和打包

**牢记一句话：定义函数时是“打包”，调用函数时是“解包”。**

| 场景 | 写法 | 含义 | 结果类型 |
| --- | --- | --- | --- |
| **定义函数时** | `def foo(*args):` | 将传入的 **位置参数** 打包成一个 **元组 (tuple)** | `args = (1, 2, 3)` |
| **定义函数时** | `def foo(**kwargs):` | 将传入的 **关键字参数** 打包成一个 **字典 (dict)** | `kwargs = {'a': 1, 'b': 2}` |
| **调用函数时** | `foo(*[1, 2, 3])` | 将列表/元组 **拆解** 成独立的位置参数传入 | 等同于 `foo(1, 2, 3)` |
| **调用函数时** | `foo(**{'a': 1, 'b': 2})` | 将字典 **拆解** 成独立的关键字参数传入 | 等同于 `foo(a=1, b=2)` |

---

### 1. 定义函数时（打包 / 收集）

```python
# 一个星（*）：多余的位置参数 -> 元组
# 两个星（**）：多余的关键字参数 -> 字典
def collect(a, b, *args, **kwargs):
    print(f"a={a}, b={b}")
    print(f"*args 打包为元组: {args}")
    print(f"**kwargs 打包为字典: {kwargs}")

# 调用测试
collect(1, 2, 3, 4, 5, name="Alice", age=18)

# 输出：
# a=1, b=2
# *args 打包为元组: (3, 4, 5)
# **kwargs 打包为字典: {'name': 'Alice', 'age': 18}
```

---

### 2. 调用函数时（解包 / 展开）

```python
def add(x, y, z):
    return x + y + z

# 一个星（*）：把列表/元组拆开，按位置传给 x,y,z
nums = [1, 2, 3]
print(add(*nums))  # 输出 6（等同于 add(1, 2, 3)），解包并一个一个传入

# 两个星（**）：把字典拆开，按名字传给 x,y,z
info = {'x': 10, 'y': 20, 'z': 30}
print(add(**info))  # 输出 60（等同于 add(x=10, y=20, z=30)）
```

---

### 3. 组合技（装饰器中的“透传”万能写法）

这是在装饰器中的写法，完美体现了“定义打包，调用解包”的对称性：

```python
def proxy_func(*args, **kwargs):
    # 此处 args 是元组，kwargs 是字典（定义时的打包）
    print("拦截成功，准备透传")

    # 此处 *args, **kwargs 又把它们拆开（调用时的解包）
    # 原封不动地把所有参数传给另一个函数
    real_func(*args, **kwargs)
```

---

### ⚠️ 特别提示

1. **顺序限制**：定义函数时，顺序必须是 `位置参数` -> `args` -> `关键字参数` -> `*kwargs`。`args` 必须在前，`*kwargs` 必须在最后。
2. **名字可以自定义**：真正起语法作用的是星号，`args` 和 `kwargs` 只是约定俗成的名字。你可以写 `spam`，但千万别这么干，保持规范！
3. **单独的一个** ：在 Python 3 中，`def foo(a, b, *, c):` 这里的  单独出现，不代表接收参数，而是**强制** `c` 必须使用关键字传参（即必须写 `c=3`）。这属于“参数分隔符”，不属于打包/解包的范畴。
