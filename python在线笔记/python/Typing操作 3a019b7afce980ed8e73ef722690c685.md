# Typing操作

在 Python 中，**类型注解（type hints）** 是一种增强代码可读性、便于静态检查的语法，不会影响运行时行为。下面从常见类型和添加方式两方面来说明。

---

### 一、常见类型注解

1. 一般定义类注解
    
    
    | 分类 | 类型 | 说明 | 示例 |
    | --- | --- | --- | --- |
    | **基本类型** | `int`, `float`, `str`, `bool`, `bytes` | 最基础的标量类型 | `age: int = 25` |
    |  | `None` | 空值类型，常与 `Optional` 联用 | `result: None = None` |
    | **容器类型** | `list`, `tuple`, `dict`, `set`, `frozenset` | 内置容器泛型（Python 3.9+可直接用） | `names: list[str] = ["a"]` |
    |  | `Sequence`, `Iterable`, `Mapping`, `MutableMapping` 等 | 抽象容器类型，位于 `collections.abc` 或 `typing` | `from typing import Sequence; seq: Sequence[int]` |
    | **组合类型** | `Union` | 多个类型之一，3.10+可用 `X | Y` | `id: Union[int, str]` 或 `id: int | str` |
    |  | `Optional` | 等价于 `Union[X, None]`，即可以为 `None` | `name: Optional[str] = None` |
    |  | `Any` | 任意类型，关闭类型检查 | `data: Any = ...` |
    | **可调用类型** | `Callable` | 描述函数的参数与返回值签名 | `func: Callable[[int, str], bool]` |
    | **字面量** | `Literal` | 限制为特定的字面值 | `mode: Literal["r", "w"]` |
    | **终态与类变量** | `Final` | 不可重新赋值 | `PI: Final[float] = 3.14` |
    |  | `ClassVar` | 类变量，不属于实例 | `count: ClassVar[int] = 0` |
    | **类型别名与新建** | `NewType` | 创建逻辑上不同的新类型 | `UserId = NewType('UserId', int)` |
    | **泛型** | `TypeVar` | 自定义泛型变量 | `T = TypeVar('T')` |
    |  | `Generic` | 定义泛型类 | `class Stack(Generic[T]): ...` |
    | **结构化类型** | `TypedDict` | 带特定键名和值类型的字典 | `class Person(TypedDict): name: str; age: int` |
    |  | `Protocol` | 结构化子类型（静态鸭子类型） | `class Flyer(Protocol): def fly(self) -> None: ...` |
    |  | `NamedTuple` | 命名元组，可注解字段 | `class Point(NamedTuple): x: float; y: float` |
    | **其他** | `NoReturn` | 函数永不返回（如抛出异常或死循环） | `def fatal() -> NoReturn: ...` |
    
    > **提示：** Python 3.10+ 支持 `X | Y` 代替 `Union[X, Y]`，`list[X]` 代替 `List[X]`（无需从 `typing` 导入），但早期版本仍需从 `typing` 模块导入对应的大写泛型。
    > 

1. 生成器函数注解
    
    对于生成器函数，返回值类型应该用 `typing.Generator`，它需要三个类型参数：
    
    ```python
    from collections.abc import Generator
    
    def prime_generator(start: int, end: int) -> Generator[int, None, None]:
        ...
    ```
    
    三个参数的含义：
    
    | 参数 | 含义 | 这里填什么 | 原因 |
    | --- | --- | --- | --- |
    | 第1个 `int` | `yield` 产出的类型 | `int` | 每次 yield 的都是质数（整数） |
    | 第2个 `None` | `send()` 接收的类型 | `None` | 这个生成器没有用 `send()` 接收值 |
    | 第3个 `None` | `return` 返回的类型 | `None` | 生成器没有显式 `return` 值 |
    
2. 覆写父类方法，需要声明@override

### 二、类型注解实例

#### 1. 变量注解

直接在变量名后加 `: 类型`。可以在赋值时同时注解，也可以单独注解。

```python
name: str = "Alice"
age: int                      # 只注解，未初始化
from typing import Optional
nickname: Optional[str] = None
```

#### 2. 函数注解

对参数和返回值分别注解，返回值用 `->` 指示。

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

from typing import Union
def get_id(value: Union[int, str]) -> str:
    return str(value)
```

#### 3. 类中的注解

- 实例属性：通常在 `__init__` 中对 `self.attr` 加注解。
- 类属性：使用 `ClassVar` 表明该变量属于类而非实例。

```python
from typing import ClassVar

class Counter:
    total: ClassVar[int] = 0

    def __init__(self) -> None:
        self.value: int = 0   # 实例属性注解
```

#### 4. 复杂类型的提前引用

当类型尚未定义时，可以用**字符串形式**的注解，或使用 `from __future__ import annotations`（Python 3.10+ 推荐）。

```python
from __future__ import annotations

class Node:
    def __init__(self, value: int, left: Node | None = None):
        self.left = left
```

旧写法：`left: 'Node' = None`。

#### 5. 泛型与类型变量

```python
from typing import TypeVar, Generic

T = TypeVar('T') #此处的T实际为一个占位符，等到实际使用的时候才确定他的类型和内容

def first_item(items: list[T]) -> T:
    return items[0]
 # 以上为泛型函数，表示输入列表为某个T类型的列表，输出也为某个T类型，当进行输入时，类型检查器会检查：
 # 1，输入的list内容是不是统一的某个T类型（可能都为str，也可能都为int，但不能是int + str）
 # 2. 得出T类型具体是哪种类型，并输出对应的某个类型的内容
 # 因此，如果你调用 first_item([1, 2, 3])，检查器推断出 T = int，所以函数返回 int；若调用 first_item(["a", "b"])，T = str，返回 str。如果你尝试 first_item([1, "a"])，检查器会报警告，因为列表元素类型不统一。
class Stack(Generic[T]): 
# 定义了一个‘泛型类’，即该class里面可以存储T类型的变量，如果定义为 Stack[int]()，则可以存储int类；定义为Stack[str]()，则可以存储str类。T就是一个延迟解释类，具体T类是什么类，在运行时根据环境决定
    def push(self, item: T) -> None: ...
    def pop(self) -> T: ...
    # 在class下开发中，T类可以当做一般类直接使用
```

#### 6. 使用 `TypedDict` 定义固定结构的字典

```python
from typing import TypedDict

class Movie(TypedDict):
    title: str
    year: int

movie: Movie = {"title": "Inception", "year": 2010}
```

#### 7. 使用 `Protocol` 实现结构类型检查

```python
from typing import Protocol

class Flyer(Protocol):
# Protocol更像是让Flyer变成一个协议，后续如果其他变量后面带上Flyer，则证明该处的变量需要是满足Flyer协议的变量，也就是它应该是一个'Flyer类'
    def fly(self) -> None: ...

def take_off(obj: Flyer) -> None:
# ‘obj: Flyer’表示obj必须是一个满足Flyer协议的变量，要属于Flyer类
    obj.fly()
```

任何实现了 `fly` 方法的对象都可以传入，无需显式继承。

#### 8. 使用 `TypeVar` 和 `ParamSpec` 来辅助包装一个装饰器

```python
from typing import Any, Callable, ParamSpec, TypeVar
from functools import wraps
import time

# 1. 日志装饰器
P = ParamSpec('P')
R = TypeVar('R')

def log(fn: Callable[P, R]) -> Callable[P, R]: #表示log装饰器接收任意签名的可调用对象，并返回一个可调用对象
    '''简单的日志装饰器'''
    @wraps(fn)
    def inner(*args: P.args, **kwargs: P.kwargs) -> R: 
        print(f'{'='*30}装饰器1作用开始{'='*30}')
        print(f'[LOG]函数{fn.__name__}即将被调用')
        # 下面这样的try方法结构更加健壮
        try:
            res = fn(*args, **kwargs)
            print(f'[LOG]函数{fn.__name__}调用完毕，返回值为{res}')
            print(f'{'='*30}装饰器1作用结束{'='*30}')
            return res
        except Exception as e:
            print(f'[LOG]函数调用失败，抛出异常：{e!r}')
            print(f'{'='*30}装饰器1作用结束{'='*300}')
            raise
    return inner
```

1. 其中 `ParamSpec` 实际上代表着“**一整组参数**”的变量，其有两个常用属性来代指变量类：

（有 `P = ParamSpec('P')`的前提）

1. `P.args` ：代表所有“位置参数“的元组类型
2. `P.kwargs` ：代表所有”关键字参数”的字典类型

1. 其中的 `TypeVar` 代表**单个类型**的变量，代码中常见 `T = TypeVar('T')` 是代表设定了一个T的未知类型变量。
